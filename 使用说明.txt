小蜘蛛桌宠 · 网页版
====================

这是一个能跑在手机 / 平板 / 电脑浏览器里的「会动、会说话」的小蜘蛛桌宠网页。
手指轻戳它会冒出台词，按住能拖着走或让它转头看你，还会自己找你搭话，
可以开一段轻快的背景音乐，也能从表情栏里挑一个表情把它「定住」。


一、在你自己的电脑上打开（本地预览）
------------------------------------
重要：这个网页会去加载 3D 模型文件，必须通过「网址」打开，不能直接双击 index.html
（直接双击是 file:// 协议，浏览器会拦住模型加载，页面会是黑的）。

任选一种本地服务器方式：

  · 如果你装了 Python（3.x）：
      在这个文件夹里打开终端，执行
          python -m http.server 8080
      然后浏览器访问  http://localhost:8080

  · 如果你装了 Node.js：
          npx serve
      或  npx http-server -p 8080
      然后访问  http://localhost:8080

  · 如果你装了 VS Code：右键 index.html →「Open with Live Server」。


二、屏幕右上角的四个按钮（手机上用手指点）
----------------------------------------
从右往左依次是：

  ✋ / 👁   按住方式切换（见第三节）
  😊        表情栏（见第五节）
  ♪ / ♫     背景音乐开关（见第四节）
  ⟲        回到原位（位置和大小还原到屏幕正中）

按钮都做到了 44×44 像素，是手指点起来最舒服的最小尺寸。


三、按住时做什么：拖拽 / 吸引转头（✋ ⇄ 👁）
------------------------------------------
点最右边那个按钮，会在两种「按住」反应之间切换：

  · ✋ 拖拽（默认）：按住拖动 = 整个小蜘蛛跟着你的手指挪位置。
  · 👁 吸引转头：**身体一点不动**，只有脑袋朝你手指按的那个方向转过去
                —— 就像电脑上鼠标滑过屏幕、它「注意到你了」那样。
                手指滑到哪儿它就看哪儿；一松手，视线平滑地回到正前方，
                位置和大小自始至终一点没变。
                这时按钮会变成 👁 并点亮成蓝色，一眼能看出现在是哪种模式。

按住了没拖（只是轻轻点一下）在两种模式下都算「戳一下」，照常触发它的反应和台词。
你的选择会被记住，下次打开还是上次那个模式。


四、背景音乐（♪ ⇄ ♫）
--------------------
点 ♪ 按钮就会响起一段**欢快的轻音乐**——钢琴式的琶音配上分解和弦，八小节循环，
可以一直当背景音乐放着。再点一下（按钮变成 ♫ 时）就关掉，会淡出，不会「咔」地断掉。

  · 这段音乐是**网页现场合成的**（用浏览器的 Web Audio 现场弹），
    不是下载来的音频文件。所以：不占体积、没有版权问题、断网也照样能响。
  · 音乐**开着**的时候，跟小蜘蛛互动（戳它、点表情）还会有配合的音效；
    音乐关掉时音效也会一起安静，不会突然出声吵到你。
  · 音乐状态会被记住。但苹果手机 / 平板（iOS）规定「网页必须等用户先点一下」
    才允许出声，所以如果你上次是开着音乐退出的，重新打开后**点一下屏幕任意位置**
    就会自动续上，不需要重新去点 ♪。


五、表情栏（😊）：演一次 / 常驻锁定
----------------------------------
点 😊 展开表情栏，里面有 15 个表情（闭眼微笑、歪头睁大眼、吓一跳、偷看你、
眨回去、单眼笑、凶狠、抬头看你、点头、摇头、扭一扭、闭眼快摇、低头捂脸……）。

每个表情有两种用法：

  · **轻点一下** → 它就演这个表情给你看一次，演完自己回到自由活动。
  · **长按（按住约半秒）** → **把这个表情定住**：之后它会一直保持这个表情，
                             像是「换了个表情站在那里」。
                             锁定后这一条会点亮成蓝色、右边显示「已锁定」。
                             **再长按同一条**（或换个表情长按）就取消了。

锁定的表情会被记住，下次打开还是那个表情。
想让它恢复自由活动，长按当前锁定的那一条取消即可。

点表情栏以外的地方，面板就收起来。

  办法 B · 让我帮你一键发布

七、网页会自己更新，不会看到旧版本
----------------------------------
这个网页做了「联网优先」的更新机制：

  · 每次打开都会去网上取最新的一版；只有在你**没有网**的时候，才会用本地缓存
    （所以第一次联网打开过之后，断网也还能开）。
  · 每次打开时会自动检查有没有新版本，一旦发现新版本，会**自动刷新一次**，
    所以你看到的永远是最新的，不用手动清缓存。

  换句话说：我改了代码之后，你重新打开（或下拉刷新）就一定是新版。

九、常见问题
------------
  Q：页面是黑的 / 小蜘蛛不出来？
  A：九成是用了双击 file:// 打开。请按上面「一」的方式用本地服务器或网址打开。

  Q：点了 ♪ 却没有声音？
  A：先确认手机没静音、音量不是 0。iOS 还要求「先碰一下屏幕」，随便点一下再点 ♪ 就好。

  Q：表情栏挡住了小蜘蛛？
  A：表情栏是临时面板，点旁边空白处就收起来了；也可以先把它拖到别处再挑表情。

  Q：长按没有锁定成功？
  A：手指要按住约半秒不松开。按下去就马上抬手会被当成「轻点」，只会演一次。

  Q：台词显示乱码 / 方块？
  A：几乎不会，文件都是 UTF-8。若遇到，确认是用现代浏览器
     （Chrome / Edge / Safari / Firefox 近几年的版本）打开。

  Q：能离线用吗？
  A：能，第一次联网打开后资源会缓存下来，之后断网也能开。
     但只要联网，它就一定会去拿最新版。

八、这次修了什么（2026-09-29）
-----------------------------
有反馈说「触屏吸引转头时抬头和低头反了」和「一部分表情微笑和不微笑反了」，
查下来一共是四个原因，都已修好并实测：

  · **上下反相**：吸引转头时竖向角度用错了符号。
    ⚠ 更正一处我自己写错过的说明：本模型里 **ParamAngleY 负值才是抬头、
    正值才是低头**（依据是本程序自己的招式表——「抬头望天」用 -16、
    「抬头看你」用 -18、「低头捂脸」用 +14）。
    当初我按「正值=抬头」的直觉改了一次，反而把原本正确的代码改反了；
    现已按上面的口径改回来并实测通过：
    「手指在上 → 抬头（读回 -27）」，「手指在下 → 低头（读回 +27）」，
    左右方向原本就是对的，没有动。

  · **微笑被硬钉成 1**：待机基准表里原来写死了「双眼微笑 = 1」，
    而每一帧都会用它去补参数，于是所有写了「不微笑（0）」的招式
    （面无表情、睁大眼睛、右眼笑……）都被顶回微笑，看着就像反了。
    现在不再写死，各个表情自己说了算——
    实测：单眼笑 = 左1右0，眨回去 = 左0右1，睁大眼 = 左右都0，闭眼微笑 = 左右都1。

  · **锁定「闭眼」类表情时眼睛闭不上**：眼睛的开合每帧都在算自然眨眼，
    锁定表情那段原先刻意跳过开合参数，结果「闭眼微笑」闭不上。
    现在改成「锁定值与眨眼值取更小的那个」——
    要闭就一直闭，该眨还是照眨（实测闭眼微笑时左右眼开合都到 0）。

  · **重启后「已锁定」是假的**：表情锁定名存进了本地记忆，但刷新后
    重建锁定参数的步骤漏了，于是按钮显示「已锁定」、参数其实没写上。
    现在会正确重建；解锁时也会把被锁过的参数复位到默认，
    不会残留上一帧的值（例如左眼一直笑、右眼不笑）。


九、这一版新增：「凶狠」表情（2026-09-29）
-----------------------------------------
表情栏里多了一个 **凶狠**（在「单眼笑」右边），轻点演一次、长按可定住。

它是「**两只眼睛一起半眯**」的样子——眼白压成一道细长的小缝，看起来凶巴巴的。
参数取值不是我拍的，是**直接对齐桌面版程序里同名的「半眯眼」**：

    桌面版 renderer.js          →  网页版「凶狠」
    squintL/R: 睁眼度 0.35       →  ParamEyeLOpen  0.35
               + 该眼微笑 1      →  ParamEyeROpen  0.35
    idleEyes : 双眼微笑 1        →  ParamEyeLSmile 1
                                →  ParamEyeRSmile 1

也就是「睁眼度 0.35 + 双眼微笑 1，两眼完全一致」。
定这个数值前，我把 0.30 / 0.35 / 0.40 三个档位都渲染出来，
和你给的那张参考图按**脸宽归一化到同一尺度**逐张比对：
0.30 太细、成了一条缝；0.40 眼白偏大；**0.35 的白面积和上眼睑走向最贴合**。
对照图在 `preview/凶狠对照.png`，面板截图在 `preview/表情面板.png`。

（顺带一提：程序里有一条「睁眼度只要不是 0，就至少是 0.3」的下限，
这是当初为了避免「眼白只剩一条小缝」加的。0.35 在这条下限之上，不受影响。）


十、自查方法（你也可以自己验）
-----------------------------
  · 吸引转头模式，手指按到屏幕最上方，它应该**抬头**；按到最下方应该**低头**。
  · 表情栏里长按「睁大眼」应锁定为不微笑；长按「闭眼微笑」应真的闭眼。
  · 长按「凶狠」应锁定成双眼半眯；和 `preview/凶狠对照.png` 左边的参考图基本一致。
  · 锁定任意表情后刷新页面，「已锁定」应当仍然生效。
